왜 CmdQ인가

한도를 기다리고 창을 오가는 시간을 큐에 맡기고, 사람은 무엇을 시킬지만 정합니다.

① 한도 대기

기존 방식
한도에 걸리면 리셋 시각까지 기다렸다가 다시 입력합니다.
CmdQ
멈춘 작업이 리셋 대기로 남았다가 리셋되면 그 세션에서 이어 실행됩니다.

② 여러 프로젝트의 순서

기존 방식
프로젝트마다 창을 띄워 두고 끝났는지 오가며 확인합니다.
CmdQ
같은 경로는 차례대로, 다른 경로는 함께 실행합니다. 체인으로 후속 작업도 이어 둡니다.

③ 머릿속 할 일

기존 방식
떠오른 명령을 기억해 두었다가 나중에 직접 입력합니다.
CmdQ
To Do에 적어 두고 준비되면 자동 큐로 승격합니다.
Claude Code의 훅이나 플러그인은 실행 중인 세션 안에서 동작합니다. 한도로 멈춘 세션을 리셋 시각에 다시 띄우거나 여러 프로젝트의 작업 순서를 정하는 일은 세션 밖에서 해야 합니다. CmdQ가 이 일을 맡고, 남은 한도와 진행 상황은 메뉴 막대에 보여 줍니다. 그래서 확장 기능과 겹치지 않고 함께 쓸 수 있습니다.

3분 만에 시작하기

Claude Code CLI가 이미 있다면 2단계부터 보십시오.

1

Claude Code CLI 설치

셋 중 하나로 설치하고, 마지막 명령으로 버전이 나오는지 확인합니다.

curl -fsSL https://claude.ai/install.sh | bash
brew install --cask claude-code
npm install -g @anthropic-ai/claude-code
claude --version
2

CmdQ 설치 후 첫 실행

DMG를 내려받아 응용 프로그램 폴더로 옮기고 실행합니다. 처음 실행하면 아래 고지가 뜨고, 동의하고 시작을 눌러야 큐와 터미널이 동작합니다.

큐에 넣은 작업은 Claude Code를 --dangerously-skip-permissions로 실행합니다. Claude Code가 대상 폴더에서 확인 없이 파일을 읽고, 쓰고, 지우며 명령을 실행합니다. 넣는 작업을 검토하고, 작업물은 버전 관리로 보호하고, 바뀌어도 되는 폴더에서만 사용해 주십시오. 실행한 작업의 결과는 사용자 책임입니다.

3

첫 작업 등록

+ 폴더로 프로젝트 탭을 열고 명령을 적습니다. Enter를 누르면 To Do에, ⌘Enter를 누르면 자동 큐에 들어갑니다. /로 시작하는 단어를 치면 스킬 목록이 뜹니다.

작동 방식

자동 큐와 To Do

자동 큐는 위에서부터 실행합니다. 경로가 다르면 기본 세 곳까지 함께 돌립니다. To Do는 보관용이라 저절로 실행되지 않습니다.

경로 · 세션 · 대화형

경로는 그 폴더에서 새 세션을 시작하고, 세션은 기존 대화를 이어 갑니다. 대화형은 큐를 거치지 않고 앱 안 터미널을 엽니다.

체인

항목을 다른 항목 아래로 끌어 넣으면 부모가 끝난 뒤 그 세션을 이어받아 실행됩니다. 부모가 실패하면 하위는 실행되지 않습니다.

한도에 걸리면 실행 중인 항목과 터미널을 리셋 대기로 돌려 두고, 리셋 시각에 그 세션에서 이어 실행합니다. 카드 없이 연 대화형 터미널도 리셋 뒤 백그라운드 터미널로 다시 이어집니다. 주간 한도도 같은 방식입니다.

사용량과 메뉴 막대

헤더에 5시간 윈도우·주간 한도 사용률과 다음 리셋까지 남은 시간이 나옵니다. 메뉴 막대 아이콘에도 같은 값과 자동 큐 현황이 보입니다.

창을 닫아도 앱은 메뉴 막대에 남아 큐를 계속 실행합니다. 아이콘의 빨간 점은 확인하지 않은 알림, 노란 점은 리셋 대기, 초록 점은 실행 중인 작업이 있다는 뜻입니다.

앱 구조 공시

Anthropic 서드파티 정책 준수를 위해 이 앱의 작동 방식을 밝힙니다.

하는 일

  • 사용자 컴퓨터에 설치된 공식 Claude Code CLI를 프로세스로 실행
  • 작업을 큐에 넣고 정해진 순서와 시각에 실행
  • 새 버전 확인 — 릴리스 정보만 내려받고 보내는 정보는 없음
  • 첫 실행 때 묻고 연결을 고른 경우에만 ~/.claude/settings.json의 statusLine을 사용량을 읽는 래퍼로 바꿈(기존 statusline 표시는 유지, 나중에를 고르면 건드리지 않음)

하지 않는 일

  • 인증 정보(OAuth 토큰, API 키) 접근·저장·전송
  • 사용 기록·작업 내용의 외부 전송
  • 사용자 데이터 수집이나 분석
인증과 네트워크 통신, Claude 호출은 모두 공식 Claude Code CLI가 담당합니다. CmdQ는 그 CLI를 언제 어떤 순서로 실행할지만 관리합니다.

개인정보와 지원 범위

수집하는 데이터가 없습니다. 모든 데이터는 ~/Library/Application Support/com.doitasap.cmdq/에만 저장되고 외부로 보내거나 제3자에게 넘기지 않습니다. 자세한 내용은 개인정보 처리방침에 있습니다.

현재 macOS 12 이상만 지원합니다. 다른 플랫폼이 필요하면 GitHub 이슈로 알려 주십시오.

CmdQ GitHub 이슈 릴리스 개인정보 처리방침 라이선스

CmdQ는 독립 제품이며 Anthropic과 제휴 관계가 없고, Anthropic의 보증이나 후원을 받지 않았습니다. Claude와 Claude Code는 Anthropic, PBC의 상표입니다. Claude Code 사용에는 사용자 본인 계정과 Usage Policy를 포함한 Anthropic 약관이 적용됩니다.
