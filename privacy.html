CmdQ ← 홈으로

개인정보 처리방침

CmdQ는 사용자 개인정보를 수집하지 않습니다.

수집하는 데이터

없습니다. CmdQ는 사용자 데이터를 외부로 전송하지 않습니다.

메뉴에서 버그 제보나 기능 요청을 누르면 GitHub의 새 이슈 화면이 브라우저에서 열립니다. 이때 주소에는 앱 버전, macOS 버전, 아키텍처 세 가지만 담기고 경로나 큐 내용, 로그는 담기지 않습니다. 링크를 여는 순간 이 세 값이 주소에 담겨 GitHub으로 전달되고, 이슈로 등록할지는 GitHub 화면에서 직접 정합니다.

데이터 저장

모든 작업 기록과 설정은 사용자 컴퓨터에만 저장됩니다.

저장 위치
~/Library/Application Support/com.doitasap.cmdq/
형식
SQLite 데이터베이스
외부 전송
없음 (제보 링크를 열 때 주소에 담겨 GitHub으로 가는 환경 정보는 위 설명 참고)

데이터베이스 파일과 로그는 소유자만 읽을 수 있도록 권한을 좁혀 저장합니다.

처음 실행할 때 묻는 statusline 연결에 동의한 경우에는 같은 폴더의 statusline/ 아래에 사용량 스냅샷과 원래 statusline 설정 백업을 소유자만 읽을 수 있게 저장합니다. 이 파일들도 사용자 컴퓨터 밖으로 보내지 않습니다.

자료 드로어에 올린 파일과 링크 수집으로 가져온 페이지 본문도 같은 폴더 아래 자료 폴더에만 저장합니다. MCP로 가져온 본문도 마찬가지입니다. 연결 모듈의 CLAUDE.md·AGENTS.md·README.md는 질문이나 [자료] 실행, 자료 대화를 시작할 때마다 같은 폴더의 linked-docs/ 아래로 사본을 만들어 claude가 읽게 합니다. 이 사본은 다른 프로젝트 문서의 복사본이라 앱 데이터에 남고, 다음 실행에서 덮어씁니다. 연결 모듈 사이의 관계와 역할은 데이터베이스에 저장합니다. 이 내용도 사용자 컴퓨터 밖으로 보내지 않습니다.

사용량 스냅샷에는 Claude Code가 statusline에 넘기는 입력 JSON이 통째로 저장됩니다. 여기에는 작업 폴더 경로(cwd), 세션 ID, 대화 기록 파일 경로(transcript_path), 모델 이름이 들어 있을 수 있습니다. CmdQ는 그중 사용량 한도(rate_limits) 값만 읽습니다.

네트워크 통신

CmdQ가 직접 보내는 요청은 업데이트 확인 한 가지입니다.

요청 대상
github.com (릴리스 정보)
보내는 내용
없음 — 파일을 내려받기만 합니다
목적
새 버전 존재 여부 확인
이 요청에는 사용자를 식별할 수 있는 정보가 담기지 않습니다. 공개된 릴리스 정보 파일을 내려받아 현재 버전과 비교할 뿐이며, 사용 기록이나 작업 내용은 포함되지 않습니다. 내려받은 업데이트는 서명을 검증한 뒤에만 설치합니다.

그 밖에 사용자가 실행한 Claude Code CLI 명령이 발생시키는 통신은 공식 CLI가 수행하는 것이며 CmdQ의 통신이 아닙니다.

MCP 수집(선택 기능)

링크 수집에서 MCP를 고르면(지금은 GitHub 주소만 지원합니다) 그때만 시작합니다. CmdQ는 페이지 하나를 가져올 때마다 수집 전용 claude -p를 띄우고 그 서버의 읽기 도구 하나만 허용합니다. 사용자가 Claude Code에 등록한 MCP 서버가 외부에 요청을 보내는 것이며, CmdQ가 직접 보내는 요청이 아닙니다. 위의 「공식 CLI가 수행하는 통신」과 같은 경계입니다.

시작 조건
사용자가 수집 방법에서 MCP를 고르고 수집 시작을 눌렀을 때만
CmdQ가 하는 일
claude mcp list로 서버 이름과 상태를 읽고, 수집 전용 claude -p를 페이지마다 실행
가져온 본문
자료 폴더에만 저장 (원본 주소·가져온 방법을 적은 머리말 포함)
한도
용량 500MB, 주소 5,000개(웹뷰 수집과 같음), 깊이 기본 3(시작할 때 1~10)
앱은 MCP 토큰, 인증 정보, MCP 설정 파일을 읽지도 저장하지도 않습니다. MCP 서버 목록은 claude mcp list가 출력하는 서버 이름과 상태로만 압니다. 인증은 Claude Code와 MCP 서버가 처리합니다.

수집 전용 claude -p는 사용자의 훅과 CLAUDE.md를 불러옵니다. 훅과 CLAUDE.md를 끄는 옵션이 MCP도 함께 끄기 때문입니다. 이를 줄이려고 저장소 밖 빈 작업 폴더에서 실행하고, 모델의 답이 아니라 도구가 돌려준 원문만 저장합니다. 페이지마다 claude를 한 번 실행하므로 페이지 수만큼 실행 비용과 시간이 듭니다. 기존의 자료 질문 대화와 요약 실행은 계속 사용자 MCP를 쓰지 못하게 막습니다.

웹뷰 수집과 로그인

웹뷰로 수집하다 로그인 화면으로 넘어가면 수집을 멈춥니다. 사용자가 같은 웹뷰에서 직접 로그인한 뒤 이어 받기를 누르면 멈춘 페이지부터 다시 받습니다. CmdQ는 비밀번호나 쿠키를 읽거나 저장하지 않습니다.

인증 정보

CmdQ는 다음을 수행하지 않습니다.

  • OAuth 토큰 또는 API 키 읽기
  • 인증 정보 저장 또는 전송
  • 로컬에 저장된 Claude Code 인증 정보 접근
  • MCP 토큰·인증 정보·MCP 설정 파일(~/.claude.json의 mcpServers, .mcp.json 등) 읽기와 저장
  • 웹뷰에 입력한 비밀번호·쿠키 읽기와 저장

모든 인증은 Claude Code CLI가 관리합니다.

사용량 조회에도 OAuth 토큰, claude.ai 쿠키, macOS 키체인을 쓰지 않습니다. 대신 Claude Code statusline이 넘겨주는 값을, 처음 실행할 때 묻는 statusline 연결에 동의했을 때만 읽습니다.

기술적 근거

이 방침은 다음 확인에 기반합니다.

  • 인증 정보를 다루는 코드 없음 — api_key·token·ANTHROPIC 관련 코드가 존재하지 않습니다
  • 앱 코드에서 HTTP로 요청하는 의존성은 업데이터 하나뿐이며, 그 요청 대상은 위에 명시한 릴리스 정보 파일입니다. MCP 수집은 앱이 요청을 보내는 것이 아니라 claude 프로세스를 실행하는 방식입니다
  • 분석·추적 도구를 포함하지 않습니다
